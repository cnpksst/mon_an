Hướng dẫn đưa lên GitHub Pages

Trang web này là Single-File HTML độc lập, hoàn toàn phù hợp chạy trên GitHub Pages miễn phí!

1

Lưu file mã nguồn

Lưu đoạn code trang web thành file tên index.html.

2

Tạo Repository mới trên GitHub

Truy cập GitHub.com, tạo kho lưu trữ mới (Public).

3

Upload file index.html

Nhấn Add file -> Upload files, kéo thả file và bấm Commit changes.

4

Bật GitHub Pages

Vào Settings -> Pages -> Chọn branch main, thư mục / (root) rồi nhấn Save.
