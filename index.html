Chỉnh sửa tên món ăn

Hướng dẫn đưa lên GitHub Pages

Trang web này được thiết kế dưới dạng Single-File HTML hoàn chỉnh. Bạn không cần cài đặt Node.js hay bundler phức tạp!

1

Tải file mã nguồn này về máy

Lưu đoạn code của trang thành file tên là index.html.

2

Tạo Repository mới trên GitHub

Truy cập GitHub.com, tạo kho lưu trữ mới (Public), ví dụ đặt tên là menu-30-days.

3

Tải file index.html lên repository

Nhấn vào nút Add file -> Upload files, kéo thả file index.html của bạn vào và nhấn Commit changes.

4

Kích hoạt GitHub Pages

Vào tab Settings của repository -> Mục Pages ở cột bên trái -> Phần Build and deployment chọn Branch là main (hoặc master) và folder là / (root) -> Nhấn Save.

Chỉ sau vài phút, GitHub sẽ cung cấp cho bạn một đường link công khai (ví dụ: https://username.github.io/menu-30-days) để truy cập mọi lúc mọi nơi!
